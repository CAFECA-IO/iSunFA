## 問題

真實報告書的表3.8 有三種版式,而解析只認一種;認不出來時**沒有任何人被告知** ——
系統表格顯示 0 筆、桑基圖不出現,而畫面上沒有一句話說明為什麼。
使用者唯一能得到的結論是「這個功能壞了」。

## 做了什麼

| 主題 | 內容 |
| --- | --- |
| 版式 B | 表頭不在第一行的表格照樣解析 |
| 版式 C | 廠址標籤寫在表格**外面**(上一行)的也讀得到 |
| 開放類別佔位列 | 一列「其他(待填)」不再否決整張表 |
| `<br>` | 讀取時就 strip(原本進到 markdown 才處理,已經來不及) |
| 使用者訊息時序 | 使用者訊息在呼叫 LLM **之前**入庫(原本 LLM 失敗連使用者說過的話都不見了) |
| 單一連線 | 修掉同時開多條推播連線;過大的匯入呼叫拆小(每次最多 4 節) |
| 匯入摘要訊息 | 匯入後在對話留一則入庫的摘要(原本匯入全程不產生任何聊天訊息:33 節落地,對話裡只剩招呼語) |
| 五層桑基圖 | 組織 → 廠址 → 範疇 → 類別 → 子代碼 |
| 已封存清單 | 可獨立滾動 |
