## 問題

盤查報告書的價值密度最高的部分是表格(表2.2 排放源、表3.8 全公司排放量),
而匯入管線原本會把它們吃掉:

- 防捏造護欄會 strip 掉 markdown 表格語法 → 逐字表格根本到不了段落
- 章節合併時 `sourceTables` 被靜默丟棄 → 前面解析對了、後面沒了
- 一張表格格式不合就整段拒收 → 一張表賠掉一整節
- 原文的表號寫法五花八門(全形空格、連字號、三層編號)→ 全被擋掉
- 頁碼切片的上界取「最後一節」而非「下一章」→ 切到別章的內容

## 做了什麼

| 主題 | 內容 |
| --- | --- |
| 照錄通道 | 新增 source table 專屬通道,讓逐字表格繞過 strip 護欄而**不放寬**護欄本身 |
| 驗證 | `CarbonSourceTableSchema`(欄位級)+ builder 的 `validateSourceTables`(渲染前),表號格式兩邊都驗(縱深防禦:表號會成為錨點語法) |
| 逐張裁決 | 壞一張丟一張並記 log,不再整段拒收;被拒的**實際值**寫進 log(只記錯誤碼看不出模型給了什麼) |
| 表號正規化 | 先收斂寫法再驗證,不因格式差異丟掉真實資料 |
| 章節合併 | `sourceTables` 隨合併帶下去(原本靜默消失) |
| 頁碼切片 | 上界改由**下一章**推導 |
| 結構圖 | 抽取獨立逾時 + 階段進度;里程碑時間軸去除軸線重複節點 |
| 匯入重試 | 只在**傳輸層**失敗時重試(LLM 內容錯誤重試沒有意義,只是再燒一次額度) |
